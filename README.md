## 🚀 Featured Work

### 🌉 Bridge Gateway — API integration service

Middleware **FastAPI** yang menjembatani platform aplikasi dengan gateway agen AI:
satu pintu REST untuk aktivasi, onboarding, chat, kalender, connector, dan billing.

| Aspek | Detail |
|---|---|
| **Runtime** | Python 3 · FastAPI · Uvicorn · Pydantic v2 |
| **Data** | PostgreSQL (schema terpisah, akses async via `asyncpg`) |
| **Integrasi** | httpx client, OAuth 2.0 (Google Calendar/Meet/Gmail), IMAP read-only, webhook poller |
| **Deploy** | Docker Compose, NGINX reverse-proxy + Basic auth, log harian persisten |
| **Ekstra** | Dashboard internal (vanilla JS), koleksi Postman, dokumentasi antar-tim |

**Yang saya kerjakan di sini:** desain kontrak API, mapping relasi 1:N antar entitas,
idempotensi request (`Idempotency-Key`), roll-up usage/billing, background job
terjadwal, serta observability lewat log terstruktur.
